עדכון עגלה: מדריך שימוש + בדיקת עדכון אוטומטית

מה חדש
  • מדריך מודרך: עולה בהתחברות הראשונה. מדגיש כל כפתור, "הבא" מעביר לשלב הבא, ו"דלג" מציג הודעה שאפשר לחזור אליו.
  • גישה קבועה למדריך: הגדרות ← מדריך שימוש ← הפעלת המדריך.
  • בדיקת עדכון אוטומטית כל 3 דקות (וגם בחזרה לאפליקציה מהרקע). כשיש עדכון מופיע סרגל "יש עדכון חדש · הפעלה מחדש", ובחזרה הבאה לאפליקציה העדכון מופעל לבד.
זה עדכון ממשק בלבד. לא צריך APK חדש.

1. חילוץ הקבצים

  1. קליק ימני על AgalaApp-update.zip ← Extract All… ← בחר את שולחן העבודה (Desktop) ← Extract.
  2. כשנשאל "Replace the files in the destination" ← Replace (מחליף 3 קבצים בתוך AgalaApp\src).

הקבצים שמוחלפים: src\app.js, src\app.css, src\app.html. שום דבר אחר לא נוגע.

2. פרסום העדכון

cd /d "C:\Users\Liad Yaakobi\Desktop\AgalaApp"
npm run publish-update
git add -A
git commit -m "tour + auto update check"
git push

הצלחה: פורסם עדכון חתום גרסה N ואחריו ה-push בלי שגיאה. המתן עד 5 דקות עד ש-GitHub מגיש את הקובץ החדש.

3. קבלת העדכון בטלפונים

בפעם הזו בלבד (כי הגרסה המותקנת עוד לא כוללת בדיקה אוטומטית): בכל טלפון, סגור את האפליקציה לגמרי ופתח מחדש. אחרי כמה שניות יופיע סרגל "יש עדכון חדש" ← הפעלה מחדש.
לחלופין: הגדרות ← גלול למטה ← בדיקת עדכון ← הפעלה מחדש.
  • מכאן והלאה הכול אוטומטי: הבדיקה רצה כל 3 דקות כשהאפליקציה פתוחה, ובכל חזרה אליה מהרקע.
  • בהגדרות ← כרטיס "אפליקציה" אפשר לראות את הגרסה. אחרי העדכון תראה (עדכון) לצד המספר.
  • המדריך יעלה אוטומטית פעם אחת בכל טלפון אחרי העדכון.

4. איך נראה המדריך

  • אמא (10 שלבים): כתיבה, הוספה, דיבור, מוצרים קבועים, הרשימה, כמות בקפיצות של חצי, שליחה ליעד, הגדרות.
  • ליעד (11 שלבים): לשוניות, סטטוס, הוספה, סימון וכמות, העתקה והזמנה, רשימה אישית, תזכורת לאמא, קוד חיבור, חזרה למדריך.
  • הכפתורים: הבא, חזרה, דלג (מציג: "אפשר לחזור למדריך בכל רגע: הגדרות ← מדריך שימוש"). כפתור "חזרה" של המכשיר מתנהג כמו "דלג".

5. אם משהו לא עובד

  • "אין שינוי" אחרי ה-push: ודא שהרצת npm run publish-update לפני ה-git, ושב-GitHub בתיקייה update יש קובץ manifest.json עם מספר גרסה חדש.
  • push נדחה: git pull --rebase origin main ואז git push.
  • "העדכון נדחה (חתימה לא תקינה)": פרסמת עם מפתח אחר. ודא שתיקיית keys היא המקורית (זו שנוצרה ב-npm run setup).
  • שלח לי צילום מסך או את הטקסט של השגיאה.
